# DocuMap

**Your Personal Document Vault & Knowledge Map** — 100% Local-First, Privacy-Sovereign Cross-Platform Application (Android, iOS & PC-compatible `DocuMap_Vault/` file structure) with **$0 developer server/hosting costs**.

## Five Core Pillars
1. **CamScanner-Grade Offline Document Scanner, Local OCR & PDF Studio** (`DocuMap_Vault/Scans/`)
2. **Obsidian-Style Markdown Workspace (`[[Wiki-Links]]`) & Structured Personal Data Logger** (`DocuMap_Vault/Notes/` & `DocuMap_Vault/Logs/`)
3. **Interactive "At-a-Glance" 2D Visual Knowledge Graph (The DocuMap)** (`DocuMap_Vault/.documap/graph_state.json`)
4. **AI Token-Saver & Context Bundler (LLM Prompt Optimizer)**
5. **Zero-Cost Cross-Platform Sync Engine (Phone <-> PC via User's Google Drive, iCloud/OneDrive Folders, or WebDAV)**
